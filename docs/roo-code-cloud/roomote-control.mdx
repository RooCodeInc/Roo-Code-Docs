# Roomote Control

Roomote Control acts as the **manual override** for your autonomous cloud workforce. While Cloud Agents are designed to work independently, there are times when human intervention is necessary-to unblock a stuck agent, clarify a requirement, or take over a complex refactor.

<img src="/img/roomote-control/overview.png" alt="Roomote Control Interface" width="800" />

## When to Use Roomote Control

Roomote Control is designed for "Human-in-the-Loop" scenarios:

1.  **Intervention**: An agent is spinning in circles or misinterpreting a prompt. Instead of cancelling the task, you can jump in, provide guidance, and let it continue.
2.  **Handoff**: You started a task on your commute via phone, and now you're at your desk. Seamlessly pick up the session where the agent left off.
3.  **Review**: An agent has requested feedback before proceeding with a destructive action (like deleting files). You can approve or deny the action remotely.

## Key Features

-   **Full Terminal Access**: View and interact with the agent's terminal output.
-   **Chat Interface**: Send new instructions or clarifications to the running agent.
-   **Action Approval**: Approve or deny tool use requests (e.g., file writes, command execution).
-   **Stop/Resume**: Pause an agent to inspect its state, then resume execution.

## How it Works

Roomote Control creates a real-time, bidirectional stream between your browser and the cloud container (or your local VS Code instance, if you are using the local extension).

## Connecting to a Session

1.  **Navigate to Dashboard**: Go to [app.roocode.com](https://app.roocode.com).
2.  **View Active Agents**: You will see a list of currently running agents under "Active Sessions".
3.  **Take Control**: Click on any session to open the Roomote Control interface.
4.  **Interact**: Type in the chat box to send commands, or use the "Stop" button to halt execution.

## Local vs. Cloud Control

Roomote Control works for both:

*   **Cloud Agents**: Agents running entirely in Roo Code Cloud infrastructure.
*   **Local Extension**: Tasks running in your VS Code on your physical machine (requires your computer to be on and VS Code to be open).

This unified interface means you have a single "Mission Control" for all your AI development, regardless of where the code is actually running.
