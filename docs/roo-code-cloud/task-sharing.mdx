# Task Sharing

Share your Roo Code tasks and collaborate with others by making tasks publicly accessible through shareable links.

:::note Login Required
You must be logged in to Roo Code Cloud to share tasks. If you haven't connected your account yet, follow the [login instructions](/roo-code-cloud/login) first.
:::

---

## Sharing from within Roo Code

1. In any active task view, locate the **link icon** <Codicon name="link" /> on the right side of the task header.
   <img src="/img/task-sharing/task-sharing-6.png" alt="Link icon in active task view" width="480" />

2. Click the link icon to open the sharing options, then select **Share Publicly**.
   <img src="/img/task-sharing/task-sharing-7.png" alt="Share Publicly option" width="400" />
   This option allows anyone with the link to access your task.

3. A public link will be generated and copied to your clipboard
    <img src="/img/task-sharing/task-sharing-8.png" alt="Public link copied confirmation" width="400" />
    You can now share this link with team members, collaborators, or anyone who needs access to view your task and its conversation history.

## Sharing from Roo Code Cloud

1. Navigate to your Roo Code Cloud account and click on the task you want to share to open the detailed task modal.
    <img src="/img/task-sharing/task-sharing-9.png" alt="Dashboard task modal with Share button" />

2. Within the detailed task modal, click the **Share** button to open the sharing options.
    <img src="/img/task-sharing/task-sharing-4.png" alt="Share Task modal" width="400" />
    Create a public link; links expire in 30 days.

3. Click **Create Share Link** to generate a new public link. Once created, you'll see the confirmation screen:
    <img src="/img/task-sharing/task-sharing-5.png" alt="Share link created confirmation" width="400" />
    From this screen you can:
    - Copy link
    - Create another link
    - View previous links
    - Delete links

The web app sharing method provides more advanced link management capabilities, including the ability to create multiple links per task and track previously generated links.

## Privacy & Security

- Tasks remain **private by default** - nothing is shared unless you explicitly create a share link
- All share links **automatically expire after 30 days** for enhanced security (unless configured otherwise by an admin in a Team account)
- Expired links cannot be accessed, ensuring your shared content doesn't remain public indefinitely
