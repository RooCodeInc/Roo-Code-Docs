# Analytics

Analytics lets you track tokens, tasks, estimated cost, and Cloud Agent credits at a glance.

## Access

- Open the Analytics tab in the web app, or go directly https://app.roocode.com/usage

## Metrics and filters

- Time ranges: Today, 7d, 30d, 90d, or All Time
- Filters: task source (All, Workspace Tasks, Cloud Tasks), Creator, Repository
- Metrics: tokens (input/output), tasks, estimated cost, and Cloud Agent credits
- Views: stacked bar chart with tabs for Tokens, Inference (cost), and Tasks; tables grouped by Creators, Models, and Repositories with totals and last‑activity timestamps.
