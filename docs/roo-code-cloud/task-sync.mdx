# Task Sync

Task Sync streams task activity from your local VS Code to Roo Code Cloud so you can monitor progress from any device and access tasks later. This feature is free for all users.

---

It creates a live, one-way stream of your task messages and status from your local VS Code to Roo Code Cloud so you can:
- Monitor long-running tasks from your phone while away from your desk
- See real-time updates (messages, mode changes, status)
- Check when a task completes without sitting in front of your IDE
- Review your cloud task history later

<img src="/img/task-sync/task-sync.png" alt="Roo Code Cloud home showing connected workspaces and tasks" width="800" />

## Getting Started

1. [Connect your IDE](/roo-code-cloud/login)
2. Open or start a task in your local Roo Code extension
3. Visit the dashboard at https://app.roocode.com to monitor in real time

Task Sync is available automatically after you connect your account. No extra configuration is required.

## Keep in mind

- Your data is never used for training or advertising purposes
- The Roo Code team doesn't have access to the contents of your tasks, unless explicitly authorized by you to debug any issues
- Probably obvious, but an Internet connection is required for live updates
